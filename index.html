The Strategy

How to Test an Algebraic Claim

Algebra is full of tempting "shortcuts" that look like they should work — but don't. One counterexample is enough to prove a statement false. You don't need a proof. You just need one number that breaks it.

1
Pick a simple test value
Try $x = 4$ or $x = 2$. Avoid 0 and 1 — they often make both sides equal accidentally.
2
Evaluate both sides independently
Compute the left side. Compute the right side. Do NOT simplify across the equals sign.
3
Compare and conclude
If the sides differ even once: False. If they match for every value you can imagine: likely True — but think about why.
Worked Example
Is $\sqrt{x^2 + 9} = x + 3$ true for all real $x$?
1
Pick $x = 4$ as a test value.
2
Left side: $\sqrt{4^2 + 9} = \sqrt{16 + 9} = \sqrt{25} = 5$
Right side: $4 + 3 = 7$
3
$5 \neq 7$, so the equation is FALSE.
✗ False — The square root does not distribute over addition. In general, $\sqrt{a^2 + b^2} \neq a + b$.
